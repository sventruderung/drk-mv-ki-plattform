HTTPS / Öffentlicher Hostname

      

        Unter diesem Hostnamen ist die Plattform per HTTPS erreichbar.
        Das Zertifikat wird automatisch über Let's Encrypt ausgestellt und
        erneuert. Beim Speichern werden die Keycloak-Redirect-URIs automatisch
        ergänzt; die endgültige Umstellung von Anmeldung und Chat erfordert
        einen einmaligen Befehl auf dem Server (wird nach dem Speichern angezeigt).

      

        
        
      

      

      

        Voraussetzungen für das Zertifikat:

        1. DNS-Eintrag des Hostnamens zeigt auf diesen Server.

        2. Ports 80 und 443 sind aus dem Internet erreichbar.

        3. Die Redirect-URIs in Keycloak werden beim Speichern automatisch
           ergänzt. Dafür braucht der Keycloak-Service-Account die Rolle
           manage-clients (realm-management).

        Hostname-Änderungen werden im Protokoll vermerkt.

    


    

      
Windows-Domäne (Active Directory)

      

        Bindet die Nutzer einer Windows-Domäne über das Active Directory an.
        Angebundene Konten erscheinen anschließend in der Nutzerliste und erhalten
        dort ihre Rollen. Konten und Passwörter bleiben im AD (nur Lesezugriff).

ELO-Dokumentensystem

      

        Anmeldung am ELO REST Service. Damit kann der Chat Dokumente im ELO-Archiv
        suchen, zusammenfassen und Kennzahlen bilden. Read-only; das Passwort wird
        verschlüsselt im Secret-Store gehalten und nie wieder angezeigt.
